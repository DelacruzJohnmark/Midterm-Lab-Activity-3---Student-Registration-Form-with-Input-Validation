# Student Registration Form with Input Validation

Laboratory Activity #3 - EDP Module 6.

## Files
- index.html
- css/style.css
- js/app.js

Open index.html directly or run it with VS Code Live Server.

Validation follows the activity:
- Student number: 24-1234-12
- Email: simplified email pattern
- Mobile: 09 + 9 digits OR +639 + 9 digits
- Password: 8+ chars, uppercase, digit, @/$/!, no spaces
- Confirm password must match
- Course: BSIT or BSCS
- Terms must be checked

The required pure functions `isValidStudentNumber(value)` and `isValidPassword(value)` are exported for CommonJS/autograder use.
